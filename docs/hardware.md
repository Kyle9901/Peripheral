# 硬件与 GPIO 接线技术文档

本文档说明 InstaCare Matter 传感器设备使用的硬件、供电方式、GPIO 分配和
接线要求。文中的 GPIO 编号均为 ESP32-S3 芯片的 GPIO 编号，不是排针的物理
序号；接线前应以开发板丝印为准。

## 1. 硬件清单

| 类别 | 型号 | 数量 | 用途 |
| --- | --- | ---: | --- |
| 主控 | ESP32-S3 开发板，16 MiB Flash、8 MiB PSRAM | 1 | 运行 Matter 固件、联网和采集数据 |
| 温湿度传感器 | DHT11 | 1 | 测量环境温度和相对湿度 |
| 光照传感器 | BH1750 模块 | 1 | 测量环境光照度，使用 I²C 通信 |
| 人体红外传感器 | HC-SR501 | 1 | 检测人体移动并生成占用状态 |
| 电源 | 5 V USB 电源，建议不低于 1 A | 1 | 为开发板和传感器供电 |

固件也支持 DHT22/AM2302，但当前默认型号是 DHT11。更换为 DHT22 后接线不变，
必须在 `idf.py menuconfig` 中同步切换传感器型号。

## 2. 主控参数

| 项目 | 参数 |
| --- | --- |
| 芯片 | ESP32-S3 |
| Flash | 16 MiB（当前固件镜像和分区表按 8 MiB 使用） |
| PSRAM | 8 MiB |
| 无线连接 | 2.4 GHz Wi-Fi、Bluetooth LE |
| 日志与烧录接口 | USB Serial/JTAG，通常显示为 `/dev/ttyACM0` |
| 工作逻辑电平 | 3.3 V |
| 固件通信 | Matter over Wi-Fi；BLE 用于首次配对 |

ESP32-S3 的 GPIO 不耐受 5 V。任何连接到 GPIO 的信号都必须确保最高电压不超过
3.3 V。

## 3. GPIO 分配总表

| ESP32-S3 引脚 | 方向 | 外设信号 | 功能 | 固件默认配置 |
| --- | --- | --- | --- | --- |
| GPIO4 | 双向 | DHT11 DATA | 温湿度单总线数据 | `CONFIG_INSTACARE_DHT_GPIO=4` |
| GPIO5 | 输入 | HC-SR501 OUT | 人体移动数字信号 | `CONFIG_INSTACARE_PIR_GPIO=5` |
| GPIO21 | 双向 | BH1750 SDA | I²C 数据 | `CONFIG_INSTACARE_BH1750_SDA_GPIO=21` |
| GPIO18 | 输出 | BH1750 SCL | I²C 时钟 | `CONFIG_INSTACARE_BH1750_SCL_GPIO=18` |
| 3V3 | 电源输出 | DHT11、BH1750 VCC | 3.3 V 供电 | — |
| 5V/VBUS | 电源 | HC-SR501 VCC | 5 V 供电 | — |
| GND | 地 | 所有模块 GND | 公共参考地 | — |

本项目不使用 GPIO22。ESP32-S3 没有 GPIO22，BH1750 的 SCL 使用 GPIO18。

## 4. 完整接线表

### 4.1 DHT11 温湿度传感器

| DHT11 引脚 | 连接到 ESP32-S3 | 说明 |
| --- | --- | --- |
| VCC / `+` | 3V3 | 使用 3.3 V 供电 |
| DATA / OUT / `S` | GPIO4 | 单总线数据 |
| GND / `-` | GND | 必须共地 |

常见三针 DHT11 模块已经带有 DATA 上拉电阻。使用四针裸传感器时，应在 DATA 与
3V3 之间接入约 4.7 kΩ 上拉电阻；裸 DHT11 正面朝向自己时，常见引脚顺序为
`VCC、DATA、NC、GND`，但仍须以器件规格或模块丝印为准。

### 4.2 BH1750 光照传感器

| BH1750 引脚 | 连接到 ESP32-S3 | 说明 |
| --- | --- | --- |
| VCC | 3V3 | 推荐使用 3.3 V，保证 I²C 电平安全 |
| GND | GND | 必须共地 |
| SDA | GPIO21 | I²C 数据线 |
| SCL | GPIO18 | I²C 时钟线 |
| ADD / ADDR | GND 或悬空 | 默认地址 `0x23` |

ADDR 接低电平时，固件默认使用 I²C 地址 `0x23`；部分模块在 ADDR 接高电平时使用
`0x5C`。如果改变 ADDR 接法，必须同步修改固件中的 BH1750 地址。常见模块已经
带有 SDA/SCL 上拉电阻；若使用裸器件，则需要按器件规格增加 I²C 上拉电阻。

### 4.3 HC-SR501 人体红外传感器

| HC-SR501 引脚 | 连接到 ESP32-S3 | 说明 |
| --- | --- | --- |
| VCC | 5V/VBUS | 模块使用 5 V 供电 |
| OUT | GPIO5 | 正常输出约 0 V 或 3.3 V |
| GND | GND | 必须共地 |

HC-SR501 模块的 OUT 通常是 3.3 V 逻辑，可以直接连接 GPIO5。上电后需要约
30–60 秒预热，预热期间 OUT 可能反复变化，不应据此判断接线故障。

模块通常有两个电位器：

- 灵敏度：调整检测距离。
- 延时：调整模块 OUT 保持高电平的硬件时间。

由于不同批次 PCB 的电位器位置可能互换，应以 PCB 丝印或实际测试为准，不能只
根据左右位置判断。每次只小幅旋转一个电位器，并观察 OUT 电平变化。

HC-SR501 的 `H/L` 跳帽控制硬件触发方式：

- `H`：可重复触发。持续检测到移动时会延长高电平时间，适合占用检测。
- `L`：不可重复触发。一次触发结束后才进入下一次检测。

本项目建议跳帽接 `H`。固件还会在最后一次检测到移动后继续保持 Matter
“有人”状态，默认 30 秒；这个软件保持时间与模块电位器的硬件延时是两个不同
参数。

只接 HC-SR501 时连接本节的三根线即可，不需要选择另一套固件；自动探测会让
Matter 只发布人体占用 Endpoint。

## 5. 接线关系示意

```text
5 V USB 电源
    │
    └── ESP32-S3 USB 接口
            │
            ├── 3V3 ───────── DHT11 VCC
            │   └──────────── BH1750 VCC
            │
            ├── 5V/VBUS ───── HC-SR501 VCC
            │
            ├── GPIO4 ─────── DHT11 DATA
            ├── GPIO5 ◄────── HC-SR501 OUT
            ├── GPIO21 ────── BH1750 SDA
            ├── GPIO18 ────── BH1750 SCL
            │
            └── GND ───────── DHT11 GND
                ├──────────── BH1750 GND
                └──────────── HC-SR501 GND
```

## 6. 供电要求

拔掉电脑后，可以使用普通 5 V USB 充电器连接开发板 USB 接口供电。建议电源输出
能力不低于 1 A；USB 线应具备可靠的供电能力。

也可以通过开发板允许作为输入的 `5V` 或 `VIN` 引脚供电，但必须先确认具体开发板
原理图和丝印。若引脚仅标记为 `VBUS`，应确认该板是否允许从该引脚反向输入。

供电注意事项：

- 不得将 5 V 接入 ESP32-S3 的 `3V3` 或任意 GPIO。
- DHT11 和 BH1750 使用 3.3 V，HC-SR501 使用 5 V。
- ESP32-S3 与三个传感器必须共地。
- 外部 5 V 引脚供电时，不建议再同时连接另一套带 5 V 输出的 USB 电源，避免倒灌。
- 上电前用万用表确认 5 V、3.3 V、GND 和正负极是否正确。

## 7. 软件配置对应关系

硬件参数可通过以下命令修改：

```bash
source /home/alkaid/esp/esp-idf/export.sh
idf.py menuconfig
```

进入：

```text
InstaCare Matter 传感器配置
```

可配置内容包括 DHT 型号、DHT GPIO、PIR GPIO、BH1750 SDA/SCL、BH1750 地址、
采样周期和 PIR 占用默认保持时间。修改 GPIO 后必须同步修改实际接线。传感器数量
无需在编译时选择，固件会根据实际接线自动探测并生成 Matter Endpoint。

当前默认采样与 Matter 属性更新时间为 5 秒。PIR 软件占用保持时间默认为 30 秒，
配对后还可以通过 Occupancy Sensor Endpoint、Cluster `0x0406`、Attribute `0x0010`
在线调整为 1–600 秒。

## 8. 上电检查

建议按以下顺序检查：

1. 断电状态下核对 VCC、GND 和信号线，确认所有模块共地。
2. 暂不连接传感器，给开发板上电，测量 3V3 对 GND 应约为 3.3 V。
3. 测量 5V/VBUS 对 GND 应约为 5 V。
4. 断电后逐个接入 DHT11、BH1750 和 HC-SR501。
5. 上电并等待 HC-SR501 预热 30–60 秒。
6. 查看串口日志，确认传感器均能读取。

正常日志示例：

```text
自动探测结果：温湿度=有 光照=有 人体红外=已登记
传感器管理已启动：采样=5000ms，重扫=30000ms，占用保持=30秒
温度=24.0 C 湿度=60.1 % 光照=109.2 lux PIR电平=低 Matter占用=否
```

常见问题：

| 现象 | 优先检查 |
| --- | --- |
| DHT11 超时 | DATA 是否接 GPIO4、是否有上拉、供电和共地是否正常 |
| BH1750 无数据 | SDA/SCL 是否接反、地址是否为 `0x23`、模块是否使用 3.3 V |
| PIR 一直为高 | 预热是否完成、H/L 跳帽、电位器延时、环境热源和模块供电 |
| PIR 完全无反应 | OUT 是否接 GPIO5、供电是否为 5 V、是否共地、灵敏度是否过低 |
| 接上传感器后电压明显下降 | 检查电源能力、短路、VCC/GND 接反和面包板接触 |

任何接线调整都应先断电，避免带电插拔造成 GPIO 或传感器损坏。
